# Open Shelf -- App Store Metadata

## App Name
Open Shelf

## Subtitle
Track your reading life

## Description
Open Shelf is a simple, private book tracker for readers who want to organise their library without giving up their data.

- Search for books using the Open Library catalogue
- Scan barcodes to add books instantly
- Organise books into shelves: Want to Read, Reading, Read, and Did Not Finish
- Track reading progress page by page
- Set yearly reading goals and monitor your pace
- View stats: books per month, genre breakdown, reading streak, and more
- Import your existing library from Goodreads via CSV
- Export your library as CSV or JSON at any time
- Home Screen and Lock Screen widgets for currently reading and goal progress
- Syncs across your devices with iCloud

All data stays on your device and in your iCloud account. No third-party analytics, no ads, no accounts required.

## Privacy Label
- Data Not Collected: Open Shelf does not collect any user data. All information is stored locally on the device and optionally synced via the user's own iCloud account.

## Content Rating
4+ (No objectionable content)

## Review Notes
- The app uses the Open Library API (openlibrary.org) to search for and display book metadata and cover images.
- iCloud sync requires a signed-in iCloud account. The app works fully offline without one.
- The Goodreads import feature requires the user to export their own CSV from goodreads.com.
- Camera access is used exclusively for barcode scanning to add books.
- Photo Library access is used exclusively for selecting custom cover images for manually added books.
